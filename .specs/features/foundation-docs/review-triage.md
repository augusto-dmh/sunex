# Review triage: foundation documents

Pull request #2 (`docs/foundation`) was reviewed in a fresh context by the `pr-review` skill: 48 inline
comments in four lanes (security 13, architecture 16, domain 11, data 8) and one PR-level
requirements summary (7 numbered items, R1–R7, and 4 notes, N1–N4). This file is the surviving
record; the comments are deleted after triage.

Every finding was judged against the documents as they are on this branch, and the CLT and eSocial
findings also against the primary-source rulebook the TDD cites (rules E-03, E-04, A-14, F-11, F-13,
F-15, F-17, U-06, U-07, C-04). A finding is false when it misreads the documents, is already answered
elsewhere, or contradicts an accepted decision.

Who triaged: the orchestrator triaged the security lane. The other lanes went to a fresh triager.
The skill asks for Fable 5.1 there, but Fable hit its usage limit, so the fallback in the ship cycle's
model guide applied and Opus 5.5 did it. The orchestrator then reviewed each verdict and changed one
(finding 38: relabel the row instead of splitting it).
